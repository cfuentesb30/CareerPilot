## 📊 API Endpoints Available

| Endpoint | Method | Purpose |
|----------|---------|---------|
| `/api/assessment/start` | POST | Start new career assessment |
| `/api/assessment/answer` | POST | Submit quiz answers |
| `/api/assessment/complete` | POST | Complete assessment & start AI analysis |
| `/api/results/{assessment_id}` | GET | Get analysis results |
| `/api/assessment/questions` | GET | Get all assessment questions |
| `/api/demo/quick-analysis` | POST | Demo AI analysis functionality |
